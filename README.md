# SolvEdu (쏠에듀) - 교육 자료 오픈마켓 플랫폼

> '쏠북(solvook.com)' 모델을 벤치마킹하여 구축된 교사와 학생을 위한 디지털 교육 콘텐츠(PDF, HWP) 오픈마켓 & 라이선싱 플랫폼입니다.

---

## 📌 프로젝트 소개 (Project Overview)
- **플랫폼명**: SolvEdu (쏠에듀)
- **주요 기능**: 중·고등학교 내신, 수능형 변형 문제, 수행평가 탐구보고서, 개념 요약본 디지털 다운로드 판매 및 구독 시스템
- **주요 타겟**: 학교/학원 교사 및 강사, 중·고등학생
- **특징**:
  - 교과서 출판사 정식 제휴 저작권 안심 라이선싱 시스템
  - 수업용 원본 편집 가능한 **HWP 한글 파일** 및 고해상도 **PDF** 동시 유통
  - [선생님 모드] / [학생 모드] 이원화 서비스 환경 제공

---

## 🌟 핵심 기능 (Key Features)

### 1. 상단 GNB & 서비스 모드 전환
- **선생님 모드 / 학생 모드 토글**: 선택한 모드에 맞추어 맞춤형 큐레이션 및 추천 교재 우선 노출
- **계층형 카테고리 트리 드롭다운**:
  - 중등 과정: 중1 과학, 중2 과학, 중3 과학 (내신/수행평가)
  - 고등 과정: 고1 통합과학 (개념완성), 수능형 융합/변형 문제 (고난도/PDF)
- **통합 검색창**: 단원명, 학교명, 출판사명(비상, 천재, 미래엔, 동아 등), 과목명 실시간 필터 검색
- **장바구니 & 내 보관함**: 카운트 뱃지, 실시간 슬라이드 드로어 및 즉시 결제 처리

### 2. 메인 홈 화면 (Main Home)
- **대형 캐러셀 배너**: 최신 추천 교재 및 이벤트 자동 롤링, 인디케이터, 이전/다음 버튼
- **실시간 판매 랭킹 TOP 5**: 과목/학년 태그, 저자, 별점, 할인율, 가격, 빠른 장바구니 담기
- **실시간 베스트 저자 카드 슬라이더**: 대치동 1타 강사, 전직 교사 등 PRO 저자 프로필 및 대표 저작물 링크

### 3. 자료 마켓 리스트 (Market List View)
- **좌측 멀티 필터바**:
  - 학년별 (중1, 중2, 중3, 고1, 수능)
  - 영역별 (개념노트, 기출문제, 수행평가)
  - 출판사별 (비상교육, 천재교육, 미래엔, 동아출판, EBS)
- **다양한 정렬 기준**: 인기순(다운로드순), 최신 등록순, 낮은 가격순, 평점 높은순

### 4. 상품 상세 페이지 (Product Detail)
- **PDF 1~2페이지 샘플 뷰어 프레임**:
  - 1p / 2p 샘플 전환 버튼
  - 불법 복제 방지용 **보안 워터마크** 레이어 탑재
  - 전체화면 뷰어 모달
- **상세 탭 메뉴**:
  - `[자료 소개 및 목차]`: 교재 특징 및 차시별 상세 목차
  - `[사용자 리뷰]`: 평점 분포 통계 및 실제 구매평, 새 리뷰 실시간 작성 기능
  - `[저작권 안내 및 환불 규정]`: 출판사 저작권 계약 안내 및 디지털 콘텐츠 환불 규정

### 5. 창작자 전용 시스템 (Seller/Author Dashboard)
- **판매자 대시보드 통계**: 당월 매출액, 정산 예정 잔액, 누적 판매 부수, 평균 평점
- **판매 대금 정산 그래프**: `Chart.js` 기반 6개월 매출 추이 라인 차트 및 수수료 10% 공제 후 정산 테이블
- **자료 업로드**: 드래그앤드롭 파일 첨부(PDF/HWP), 학년/출판사/가격/설명 입력 후 마켓 즉시 등록
- **내 자료 관리 & 실시간 가격 수정**: 등록 자료의 판매 가격을 실시간으로 직접 수정 및 반영

## 🛠️ 기술 스택 (Tech Stack)
- **Frontend**: HTML5, Vanilla JavaScript (ES6+), Tailwind CSS v3
- **Icons**: Lucide Icons
- **Visuals & Charts**: Chart.js
- **Typography**: Pretendard Font

## 🚀 실행 방법 (Getting Started)

별도의 복잡한 빌드 과정 없이 `index.html`을 브라우저에서 바로 열거나 로컬 웹 서버를 실행하여 동작을 확인할 수 있습니다.

```bash
# 브라우저에서 index.html 직접 열기 (더블 클릭)
# 또는 Python 간이 서버 실행
python -m http.server 8080
```
브라우저 주소창에 `http://localhost:8080`을 입력하여 접속합니다.
